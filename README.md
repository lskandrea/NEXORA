# NEXORA

Application SaaS de gestion d'activité pour indépendants et petites entreprises.

## Stack

- Next.js 15 / TypeScript / React 19
- Supabase (authentification et données)
- Stripe (abonnements en mode test)

## État du projet

Le dépôt est initialisé. Le code source de NEXORA v0.2.1 n'a pas encore été importé dans ce dépôt.

Le projet inclut un tableau de bord, des espaces de travail, des projets, des tâches et la facturation Stripe. Avant toute mise en production, il faudra configurer Supabase et Stripe et exécuter les tests.

Ne jamais publier les fichiers `.env.local` ni les clés secrètes.
